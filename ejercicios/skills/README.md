# Skills

Instrucciones para tu coding agent. Para usarlas, abre Claude Code en tu repo y pídele que lea y siga el `SKILL.md`.

| [`linear`](linear/SKILL.md) | Leer y escribir en Linear (issues, comentarios, proyectos) con `LINEAR_API_KEY` | [OpenSymphony](https://github.com/kumanday/OpenSymphony), licencia MIT, © 2026 Leonardo Gonzalez. Rutas ajustadas a `skills/linear/`, relativas a `ejercicios/` |
