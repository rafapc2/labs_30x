# Hitos del proyecto

## M1: Cimientos y autenticación

Objetivo: Dejar el proyecto ejecutable con `docker compose up`, la base de datos creada y el inicio de sesión funcionando.

Tareas:

- TASK-001 Andamiaje del proyecto y Docker Compose
- TASK-002 Esquema de base de datos y migraciones
- TASK-003 Autenticación con Google o GitHub

## M2: Análisis y generación

Objetivo: Pegar una URL y obtener una app en borrador con contenido extraído, metadata y herramientas.

Tareas:

- TASK-004 Lectura segura de URLs
- TASK-005 Extracción y almacenamiento del contenido
- TASK-006 Generación de metadata con el modelo de lenguaje
- TASK-007 Endpoint POST /api/apps
- TASK-016 Interfaz base: inicio de sesión y formulario de URL

## M3: Simulador, verificación y despliegue MCP

Objetivo: Probar la app en un simulador, verificar la propiedad y dejarla respondiendo por MCP.

Tareas:

- TASK-008 Herramientas de la app: buscar, contacto y listar_paginas
- TASK-009 Servidor MCP multi-app
- TASK-010 Verificación de propiedad del sitio
- TASK-011 Simulador de ChatGPT
- TASK-012 Despliegue y retiro de apps

## M4: Paquete, panel y demo

Objetivo: Entregar el paquete de publicación, el panel de uso y la demo de punta a punta con ChatGPT.

Tareas:

- TASK-013 Panel básico de uso
- TASK-014 Investigar el formato del ZIP de envío a ChatGPT
- TASK-015 Paquete de publicación y guía
- TASK-017 Túnel ngrok y guion de la demo con ChatGPT
- TASK-018 Pruebas de aceptación de extremo a extremo
